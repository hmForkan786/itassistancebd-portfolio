# Content Management Guide

## Projects
Create with title, slug (auto), status, short description, description, purpose, problem/solution/implementation/results, limitations (one per line), technologies (comma-separated), client visibility, duration, URLs, sort order, featured, published_at. Publish when ready.

## Testimonials
Create with client name, role, company, review text, rating 1-5, review date, project association. Verify authenticity, approve, publish. Only approved+published+verified show publicly.

## Metrics
Create metric_key (snake_case), label, value, unit, source type (manual/derived), source reference. Verify and enable before public display. No fabricated values.

## Services/Skills
Create/edit, enable/disable, set sort order, featured (services).

## Settings
Key/value typed store; mark public/private. Secret values must not be public.

## Messages
View, mark read/replied/archived, notes, delete. Never exposed publicly.
